## 🧭 Overview

Wave Ledger Forge 2026 is an independent community project that reimagines how small businesses, freelancers, and solo accountants interact with their financial records on Windows. Instead of treating bookkeeping like a chore that only gets attention at the end of the quarter, this project approaches it the way a gardener approaches a greenhouse — a daily, gentle habit that produces compounding results.

The repository centers on a Windows-native companion workflow for individuals who want Wave-style accounting practices available on their desktop. That means invoicing, expense tracking, reconciliation views, and income summaries — all presented with a clean, native-feeling interface that respects your time and your screen space.

Whether you run a one-person consultancy, a design studio, a small retail shop, or a weekend Etsy operation, Wave Ledger Forge aims to be the quiet assistant that never asks for a raise.

## 💡 Why Wave Ledger Forge Exists

Most accounting tooling for Windows falls into one of two camps: enterprise giants that require a training seminar to open a single invoice, or featherweight notebooks that can't tell the difference between a liability and a latte.

Wave Ledger Forge sits between those extremes. It's a deliberate middle path — an accountant's pocket knife for Windows 11 and Windows 10 machines.

The project was born from a simple observation: countless small operators admire the workflow of modern cloud accounting, but they want that same workflow grounded on their own desktop, with a familiar Start menu shortcut, predictable file locations, and offline resilience.

Every design decision in this repository flows from that observation.

## 🚀 Installation Walkthrough

Getting the application onto your Windows desktop is a short, linear journey. Follow along at a leisurely pace — nothing here needs to be rushed.

1. **Acquire the package.** Locate the distribution archive that matches your Windows architecture, typically labeled for x64 or ARM64. The file will arrive as a single compressed bundle.
2. **Verify the checksum.** Before extracting, compare the hash listed alongside the package against the hash on your machine. This single step has saved more weekends than any antivirus.
3. **Extract to a permanent location.** Avoid dropping the application into a temporary folder. A path such as C:\Apps\WaveLedgerForge works well and keeps things tidy.
4. **Launch the installer.** Double-click the main executable. Windows may display a SmartScreen prompt for new applications — choose the option to run anyway once you've confirmed the publisher details.
5. **Follow the on-screen prompts.** Choose your language, pick a data directory, and decide whether to enable automatic updates.
6. **Finish and sign in.** The first launch presents a gentle onboarding wizard, which doubles as the setup assistant described in the next section.

If anything misbehaves, the troubleshooting chapter near the bottom of this document covers the most common snags.

## 🧱 First-Time Setup Guide

The onboarding wizard is designed to feel like a friendly librarian rather than an auditor. It walks through six short panels:

1. **Business profile** — Name, industry, fiscal year start, and base currency.
2. **Chart of accounts** — Pick a template (freelancer, retail, services, mixed) or import your own.
3. **Tax configuration** — Select the region and applicable default rates.
4. **Bank connections** — Optional. You can link accounts now or later.
5. **Backup preferences** — Choose a folder, set the retention window, and toggle cloud mirroring.
6. **Theme and language** — Because the interface should feel like yours from minute one.

The wizard can be re-run later from Settings → Onboarding, which is handy if your business changes shape.

## 🔁 Everyday Workflows

### Creating an Invoice

Open the Invoices tab, click the Plus button, and fill in the client, line items, and due date. The preview pane updates live, showing exactly how the invoice will appear in the PDF export. Save it as a draft, or send it directly through the optional email bridge.

### Logging an Expense

Drag a receipt image onto the Expenses canvas. The application extracts the vendor, amount, and date, then asks you to confirm the category. Confirm with Enter, and the ledger updates. It's the closest thing to magic that accounting software has ever produced.

### Reconciling a Statement

Import a bank statement as CSV or PDF. The reconciliation canvas lines up your internal records alongside the imported entries. Matching rows glow green. Unmatched rows glow amber. You resolve each one with a click, and the ledger reaches a state accountants call "peaceful."

### Closing the Month

When the last day of the month arrives, run the Month Close assistant. It sweeps through unreconciled entries, unsent invoices, and unrecorded expenses, then produces a summary you can archive or email to your accountant.

## ❓ Frequently Asked Questions

**Q: Is this affiliated with Wave or any parent company?**
A: No. This is an independent, community-driven project. It borrows inspiration from modern cloud accounting workflows but is not published or endorsed by any external brand.

**Q: Does it work on Windows 10?**
A: Yes. The 2026 release targets both Windows 11 and Windows 10 (build 19044 or newer).

**Q: Can I run it entirely offline?**
A: Absolutely. Sync and cloud mirroring are optional. The application is designed to be a fully functional local-first workspace.

**Q: What happens to my data if I uninstall?**
A: Your ledger folder remains untouched unless you explicitly choose to remove it during uninstall. Backups persist for the retention window you configured.

**Q: Do I need an accountant's background?**
A: Not at all. The onboarding wizard explains each concept in plain language, and the help center expands on any topic with examples.

**Q: Are updates automatic?**
A: Only if you opt in. Otherwise, the app quietly notifies you when a new build is available.
